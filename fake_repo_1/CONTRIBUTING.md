# Contributing Guidelines

Welcome to the demo repository! Please follow these coding standards:

## Python Style Rules
1. **Type Hinting**: All function arguments and return types MUST have Python type hints.
2. **Docstrings**: Every function must have a brief docstring explaining what it does.
3. **No Global Variables**: Do not use global variables for state management.
4. **Security**: Never hardcode API keys or passwords in the source code. Use environment variables instead.
